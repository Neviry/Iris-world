# 📮 发文指南

以后煊煊发文，就再也不用看任何平台的脸色了。日常流程如下：

## 日常发文

1. **写**：在 Obsidian 里正常写笔记（想加图片、callout、双链都行）
2. **放**：把 `.md` 文件（连同图片）放进项目的 `content` 文件夹
3. **推**：告诉安安"发布"，或者自己执行：

```bash
git add .
git commit -m "new post"
git push
```

推送后一到两分钟，网页自动更新，全世界都能看到。

## 私密内容怎么办

放在 `content/private` 文件夹里的内容**永远不会被构建进网站**。
树洞、草稿、小日记，都可以安心放在那里。

## 笔记头部小设置

每篇笔记最上面可以写几行"元信息"：

```markdown
---
title: 文章标题
date: 2026-10-12
draft: false
---
```

- `title`：显示的标题
- `date`：文章日期
- `draft: true` 的文章不会发布（写一半先藏着）
